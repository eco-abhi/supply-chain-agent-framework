# DataCo Smart Supply Chain dataset

Place `DataCoSupplyChainDataset.csv` in this directory.

Download: [DataCo Smart Supply Chain](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)
(or the common mirror used as `DataCoSupplyChainDataset.csv`).

Encoding is typically `latin-1`. Runtime assumes the CSV is already present.
